# ADR 0023 — Linear: one team, projects = milestones, labels = domains

**Status**: Accepted (2026-08-20)

## Context

Work is orchestrated continuously across many agents; a single shared board keeps
the human owner and the agents aligned.

## Decision

- One Linear team: **SarnautCore**.
- **Projects mirror milestones** (M0 Pipelines & Foundations, M1 Zone Walkabout,
  M2 Vertical Slice) plus a standing **Asset Pipeline** project.
- **Labels are domains**: server, client, tools, data, infra, web, art.

## Consequences

- Every substantive work item gets a Linear issue; agents update status as they go.
